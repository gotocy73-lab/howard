# CSR협력2팀 주간보고 도구 — 설치 안내

구글 시트에 데이터를 저장하는 웹 도구입니다. 팀원은 링크만 열면 되고, 회사 구글 계정으로 로그인되어 있으면 바로 쓸 수 있습니다.

- 걸리는 시간: 5~10분 (한 번만)
- 필요한 것: 회사(miral.org) 구글 계정, 이 폴더의 `Code.gs`와 `Index.html`

## 1. 데이터가 쌓일 구글 시트 만들기

1. **회사 구글 계정**으로 로그인한 브라우저에서 <https://sheets.new> 를 엽니다.
2. 왼쪽 위 제목을 `CSR협력2팀 주간보고 데이터`로 바꿉니다.

이 시트를 만든 사람이 도구의 주인이 됩니다. 팀 공유 드라이브로 옮겨도 됩니다.

## 2. 코드 붙여넣기

1. 시트 메뉴에서 **확장 프로그램 → Apps Script**를 누릅니다. 새 탭에 편집기가 열립니다.
2. 왼쪽 위 프로젝트 이름(`제목 없는 프로젝트`)을 `주간보고`로 바꿉니다.
3. 가운데 편집창에 있는 내용을 **전부 지우고**, `Code.gs` 파일 내용을 **전부 붙여넣습니다**.
4. 왼쪽 **파일** 옆의 **＋** 를 누르고 **HTML**을 고릅니다. 이름을 `Index`라고 적고 Enter를 누릅니다. (대문자 I, 확장자는 자동으로 붙습니다)
5. 새로 생긴 `Index.html`의 내용을 **전부 지우고**, `Index.html` 파일 내용을 **전부 붙여넣습니다**.
6. 위쪽 **💾 저장** 아이콘을 누릅니다.

## 3. 웹 앱으로 배포하기

1. 오른쪽 위 **배포 → 새 배포**를 누릅니다.
2. **유형 선택** 옆 톱니바퀴(⚙)를 눌러 **웹 앱**을 고릅니다.
3. 아래처럼 고릅니다.
   - 설명: `주간보고`
   - 다음 사용자 인증 정보로 실행: **나**
   - 액세스 권한이 있는 사용자: **밀알복지재단 내 모든 사용자** (조직 이름으로 표시됩니다)
4. **배포**를 누릅니다.
5. **액세스 승인**이 나오면 본인 계정을 고르고 **허용**을 누릅니다. 이 스크립트가 방금 만든 시트를 읽고 쓰도록 허락하는 단계입니다.
6. 화면에 나오는 **웹 앱 URL**을 복사합니다. 이 주소가 팀에 공유할 링크입니다.

링크를 한 번 열어 보세요. 시트에 `주차`, `업무`, `설정` 탭이 자동으로 생깁니다.

## 4. 팀원 등록하기 (우리 팀만 쓰게 하기)

처음에는 **배포한 본인만** 쓸 수 있습니다.

1. 구글 시트의 **설정** 탭을 엽니다.
2. `허용 이메일` 옆 칸에 팀원의 회사 이메일을 쉼표로 구분해 적습니다.
   예: `hong@miral.org, kim@miral.org, lee@miral.org`
3. 팀원에게 3단계에서 복사한 링크를 보냅니다.

등록되지 않은 사람이 링크를 열면 "접근 권한이 없습니다"와 함께 자기 이메일이 표시됩니다. 그 이메일을 위 칸에 추가하면 됩니다.
재단 전체에 열고 싶으면 칸에 별표(`*`) 하나만 적습니다.

## 5. (선택) 이번 주 내용 한 번에 넣기

기존 구글 시트의 11월 3주차(11/16~11/20) 내용을 옮겨 둔 `Seed.gs`가 있습니다.

1. Apps Script 편집기에서 **파일 옆 ＋ → 스크립트**를 누르고 이름을 `Seed`로 적습니다.
2. 내용을 전부 지우고 `Seed.gs` 내용을 붙여넣은 뒤 저장합니다.
3. 위쪽 함수 선택 칸에서 `importThisWeek`를 고르고 **▶ 실행**을 **한 번만** 누릅니다.
4. 끝나면 `Seed.gs` 파일은 지워도 됩니다.

## 쓰는 방법

- 칸을 눌러 바로 고칩니다. 입력을 잠시 멈추면 자동으로 저장됩니다.
- 다른 팀원이 고친 내용은 약 20초마다 화면에 반영됩니다.
- **새 주차**를 누르면 직전 주차의 담당자·기업 목록을 가져와 다음 주를 만듭니다.
- 입력한 내용은 구글 시트의 `주차`, `업무` 탭에 그대로 쌓입니다. 시트에서 직접 고쳐도 도구에 반영됩니다.

## 주의할 점

- 시트의 **첫 줄(제목 줄)과 `ID` 칸, 탭 이름은 바꾸지 마세요.** 도구가 이 값으로 줄을 찾습니다.
- 두 사람이 **같은 칸을 동시에** 고치면 나중에 저장한 내용이 남습니다. 서로 다른 줄을 고치는 것은 문제없습니다.
- 지운 내용을 되살려야 하면 구글 시트의 **파일 → 버전 기록**에서 복원할 수 있습니다.

## 나중에 코드를 고쳤을 때

편집기에서 코드를 바꾼 뒤 **배포 → 배포 관리 → 연필(✏) → 버전: 새 버전 → 배포**를 누릅니다. 링크 주소는 그대로 유지됩니다.

## 문제가 생기면

| 증상 | 확인할 것 |
|---|---|
| 배포 화면에 "조직 내 모든 사용자"가 없음 | 개인 Gmail 계정으로 시트를 만든 경우입니다. 회사 계정으로 다시 만드세요. |
| 팀원에게 "접근 권한이 없습니다"가 뜸 | 화면에 표시된 이메일을 `설정` 탭의 허용 이메일에 추가하세요. |
| 팀원이 구글 계정 여러 개로 로그인되어 있어 열리지 않음 | 시크릿 창에서 회사 계정 하나로만 로그인해 열어 보세요. |
| "저장하지 못했습니다"가 뜸 | 인터넷 연결을 확인하고 페이지를 새로 고치세요. 계속되면 시트의 탭 이름이나 첫 줄이 바뀌지 않았는지 확인하세요. |
